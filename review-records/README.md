# review-records

検証・承認の記録を残す場所です。**版管理対象です。** コミットしてから次の工程へ進みます。

フックがこのディレクトリを見て、記録が無ければコミットとマージを止めます。

## 構成

| パス | 内容 | 誰が書くか |
|---|---|---|
| `security-review/<ブランチ名>.md` | コミット前のセキュリティレビュー | security-review |
| `reviewer/pr<番号>.md` | コードレビューの判定 | reviewer |
| `pr-checker/pr<番号>.md` | PR タイトル・本文の整備とユーザーテスト記載の記録 | pr-checker |

ブランチ名に `/` が含まれる場合は `-` に置き換えます。

## security-review の記録

ステージ済み差分の**指紋**を必ず本文に書きます。指紋はフックが表示します。差分を変更すると指紋が変わるため、古い記録でコミットを通すことはできません。

```markdown
# セキュリティレビュー : <ブランチ名>

- 実施日時（JST）：YYYY-MM-DD HH:MM
- 差分の指紋：<16桁>
- 対象ファイル：（一覧）

## 判定

合格 / 不合格

## 確認した観点

（.claude/OWASP10.md の各観点について、該当の有無と根拠を書きます。基準の本文は転記しません）

## 指摘

（無い場合は「指摘はありません。」と書きます）
```

## reviewer の記録

`不合格` の文字列が残っている間、フックがマージを止めます。

```markdown
# コードレビュー : PR #<番号>

- 実施日時（JST）：YYYY-MM-DD HH:MM
- 対象 Issue：#<番号>

## 判定

合格 / 不合格

## Issue の受け入れ要件

| 要件 | 判定 | 根拠 |
|---|---|---|

## 各基準への適合

| 基準 | 判定 | 備考 |
|---|---|---|
| CC | | |
| OWASP10 | | |
| QC10 | | |
| CRAP | | |
| DP | | |
| TM | | |

## 指摘

（重大度を 不合格 / 要修正 / 提案 に分けて書きます）
```

## pr-checker の記録

```markdown
# PR 整備 : PR #<番号>

- 実施日時（JST）：YYYY-MM-DD HH:MM

## 反映した内容

- タイトル：（変更後）
- 本文：日本語化の有無、ユーザーテスト手順の追加の有無

## ユーザーテスト手順

（ブラウザだけで確認できる手順になっていることを確認した旨と、確認した項目数を書きます）
```

## 注意

`.claude/` 直下の md は秘匿情報です。**基準名と判定だけを書き、内容を転記しません。**
