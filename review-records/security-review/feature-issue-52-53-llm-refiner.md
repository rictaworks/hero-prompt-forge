## 判断したこと

### 最安のモデルを選びます

2026-08-27 時点の公表価格（Google の Gemini API の料金ページ）では、文章モデルの単価は次のとおりです。

| モデル | 入力（100 万トークン） | 出力（100 万トークン） |
|---|---|---|
| **gemini-2.5-flash-lite** | **0.10 ドル** | **0.40 ドル** |
| gemini-2.5-flash | 0.30 ドル | 2.50 ドル |
| gemini-3.1-flash-lite | 0.25 ドル | 1.50 ドル |
| gemini-3.5-flash-lite | 0.30 ドル | 2.50 ドル |

**`gemini-2.5-flash-lite` が最も安く、次に安いものと比べて出力の単価が 6 分の 1 以下です。** 磨く対象は 1 案あたり 10 件ほどの短い英文ですので、**出力の単価が効きます。**

**価格は変わります。** 変わったときに設定ファイルだけを直せるよう、実装の中へ書きません。

### 送るのは、磨く対象の英文だけです

**サービス概要をそのまま送りません。** 概要には第三者の名前が入り得ます。**規則を通したあとの素材だけ**を送ります。

**認証情報・利用者の識別子・セッションを送りません。** 送る内容は、指示文と英文の並びだけです。

### 磨いたつもりで壊れている状態を残しません

素材の数が変わった場合・日本語が混ざった場合・**コピースペースの指定が消えた場合**は、その場で失敗させます。コピースペースの確保は最上位の指定です（requirements.md 4.1 の 5、4.2）。

### 黙って縮退しません

縮退した案には**印と理由**を残します。印が無いと、利用者は「なぜ表現が素っ気ないのか」を知る手立てがありません。

理由は 3 通りに分けます。

- `llm_unavailable`：API キーが用意されていません
- `llm_failed`：呼び出しが失敗しました
- `llm_unusable_result`：磨いた結果を受け取れませんでした

## 申し送り

**この PR は、実際の呼び出しを行いません。** API キーが用意されていない環境では、**呼び出さずに縮退します。** 有償の呼び出しを始める前に、**単価の見積もりをお客さまへ提示してください**（CLAUDE.md）。

**LangChain（LangSmith / LangGraph）はまだ使っていません。** requirements.md の技術スタックはプロンプト精緻化に LangChain を挙げています。**別 Issue として切り出します。**

**組み立ての段（issue #146）へつなぐのは、この PR の外です。** 展開のあと・整形の前に `DegradedComposer#compose` を挟んでください。
