## 直した弱点（2回目）

reviewer が実測で「権利上まったく問題のないサービス概要 27 件のうち 18 件を差し戻す」ことを示しました。誤検出は、権利の問題と関係のない利用者を締め出します。次のとおり直しました。

| 弱点 | 対応 |
|---|---|
| 職種・立場の敬称（オーナー様・担当者様・代表取締役社長）を人名として弾いていました | 敬称を「さん」「氏」に絞り、見送る語（職種・立場・書式）を規則へ持たせました |
| 「ロゴ」という語だけで弾いていました。ロゴ制作を業務にする利用者が使えませんでした | 「◯◯のロゴ」の形に限り、自社を指す語を見送ります |
| 企業名の単純な言及（連携先・取引先）を弾いていました | まねる意図の言い回しと揃った場合に限ります |
| 一般名詞と重なる作品名（衣類のワンピース・媒体名の週刊少年）を弾いていました | 規則から外しました |
| 文字列でない値を黙って文字列へ直していました | `nil` 以外の非文字列は失敗させます |
| 空の規則が黙って素通りしていました | 規則が空・検出の語が空のいずれも、読み込みの時点で失敗させます |
| 読み込みの失敗が3種類の例外に分かれていました | すべて `InvalidRuleError` へ寄せました |

| 検査 | 方法 | 結果 |

| 正規表現の安全性 | reviewer の実測 | 入れ子の繰り返しを持たず、1000 文字で最大 0.64 ミリ秒です。入力の長さは上位の層が 1000 文字に制限しています |
