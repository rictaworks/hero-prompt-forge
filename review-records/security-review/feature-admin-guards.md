## 判断したこと

**資格情報の読み出しと照合を、コントローラの外へ出します。** これまでは「照合が通ったか」と「実施者を控えるか」が別々の式で、**通らなかった名前も控えるように書き換えても、どのテストにも当たりませんでした。** 返り値をひとつにまとめると、控える対象は照合の結果そのものになります。

**呼び名（`AuthenticatesAdmin::USER_NAME_KEY` 等）は引き継ぎます。** 既存のテストと運用の手順が参照しているためです。**実体は `Admin::Credentials` の側に 1 つだけ置きます。**

**雛形の属性の値も、直書きの検査の対象にします。** `alt` ・ `title` ・ `placeholder` の文言は利用者の目に触れます。**いまの雛形に属性の文言はありませんので、この変更で検出が増えることはありません**（本体の検査は 0 件のままです）。

**見送ったもの**：issue #177 の提案 14（内訳の見出しを `<th>` から `<td>` へ移す変異）は、テストの中に「数そのものは対象にしません」と理由が書かれた意図的な割り切りですので、issue の記載どおり見送ります。
