| 検め | 内容 |
|---|---|
| README に書いた画面は、すべて実装されています | `src/frontend/src/app` の下の `page.tsx` と突き合わせます |
| 実装した画面は、すべて README に書かれています | **書き漏らしも捕まえます** |
| README に書いた経路は、すべて実装されています | `config/routes.rb` と控えの並びと突き合わせます |
| SPEC の図は、すべて Mermaid のコード塀で閉じています | 閉じ忘れると、図が本文として表示されます |
| SPEC の索引は、置いてある文書をすべて挙げます | 足した文書が索引から漏れません |

**実際に効くことを確かめました。** 法務のページ（`/terms` ・ `/privacy` ・ `/commerce`）が `main` に入る前は、**この検査が赤でした**。入った後に緑になりました。
