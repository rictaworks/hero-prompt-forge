## 判断したこと

**抽象背景の案からは、人物を避ける構図を外します。** 具体物を置かない案に「後ろ姿の被写体」を指示すると、抽象背景という指定と食い違います。**外した事実はノートへ残します。** アートディレクションノート（issue #51）が、それを利用者へ見せます。

**2 回展開しません。** 案の中でさらに 3 案へ分かれ、9 案になります。

**スタイル仕様化を通っていない下書きは展開しません。** どの指示を選び直せばよいのか決められません。既定へ寄せず、その場で失敗させます。

## 判断したこと

**外す素材は、役割の名前で指定します。** 素材の文字列を照合して見分けると、言い回しが変わったときに黙って外れます。**コピースペースの段が、どの指示がどの役割かを控えへ残すようにしました。**

**余白の確保と、余白を静かに保つ指定は外しません。** 最上位の指定です（requirements.md 4.1 の 5）。外すのは、被写体があることを前提にした指示だけです。

**約束を文章で置くだけにしません。** 「コピースペースの指定を打ち消す指示を書きません」という約束を、読み込み時の検めとして実装しました。規則は人が編集するデータです。

**版が食い違えば、その場で止めます。** 控えの指示と、いま引ける指示が食い違うと、`zip` が足りない分を `nil` で埋め、撮影指示が記録も残さずに落ちます。**4.2 は「撮影指示を欠くプロンプトは出力しない」と定めています。**

## 申し送り

**実写系以外は、案の違いが主役の置き方だけになります。** 規則辞書で一覧の形を持つのは `photoreal` の `lens_mm` と `person_safety` だけです。**イラスト・3D・抽象の系統にも選べる値を持たせることを、規則辞書の編集画面（issue #65）で扱ってください。**

**設定を読み込むクラスが増えています。** `CopySpaceRules` ・ `WordForms` ・ `RomajiTable` ・ `VariationRules` ・ `IntegrationRules` ・ `ColorNameTable` が、それぞれ「読む → 検める → 凍らせる → 覚える」を書いています。**共通の土台へまとめる余地があります。**
