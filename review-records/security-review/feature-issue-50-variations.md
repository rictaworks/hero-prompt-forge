## 判断したこと

**主役の置き方だけを変えません。** スタイル仕様化規則が一覧で選べる値を持つ場合（レンズ焦点距離・人物を避ける構図）は、**案ごとに別の値へ選び直します。** 同じレンズ・同じ構図のまま主役だけを入れ替えても、3 案が似通います。**4.2 が求めるのは「構図の異なる 3 案」です。**

**抽象背景の案からは、人物を避ける構図を外します。** 具体物を置かない案に「後ろ姿の被写体」を指示すると、抽象背景という指定と食い違います。**外した事実はノートへ残します。** アートディレクションノート（issue #51）が、それを利用者へ見せます。

**一覧を一巡したら先頭へ戻ります。** 案の数（3）と、選べる値の数は一致しません。足りない場合に生成を止めるのは、利用者にとって不利益です。

**2 回展開しません。** 案の中でさらに 3 案へ分かれ、9 案になります。

**スタイル仕様化を通っていない下書きは展開しません。** どの指示を選び直せばよいのか決められません。既定へ寄せず、その場で失敗させます。

**元の下書きを変えません。** 3 案はそれぞれ別の下書きとして返します。
