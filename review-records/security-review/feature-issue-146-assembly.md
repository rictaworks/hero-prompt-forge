## 判断したこと

**禁止入力の検出を、入力の正規化より先に置きます。** 正規化は選べない値をその場で失敗させますので、**正規化を先に置くと、権利に関わる理由ではなく形式の誤りとして返ります。** お客さまには、権利の問題であることをお伝えする必要があります。

**統合は、案ごとに行います。** 先に統合すると、案によって外した素材を指す説明が控えへ残ります。**「弱めて残しました」と書いてある素材が、実際には外れている**状態になります。

**出力の直前に、コピースペースの確保を必ず確かめます。** 4.2 の定めです。**確かめるのはノートではなく、実際の素材です。** ノートは後段で消えませんが、素材は消えます。テストでは、統合の段が余白の素材を落とす場合を作り、**出力しないことを固定しました。**

**規則辞書の版が途中で変わったら、その場で失敗させます。** どの版で作ったのかを追えなくなります（requirements.md 7.2）。

**整形の結果に付く控え（画像の大きさのすり替え）は、まだノートへ混ぜていません。** `Formatted#notes` にあります。**アートディレクションノートへ足す形を、issue #73（結果の画面）までに決めてください。**

**非同期ジョブ（issue #54）から呼ぶのは、この段です。**

## 工程の並びを見直しました

```

3. 日本語固有名詞の保持
4. スタイル系統の仕様化
```

**requirements.md 4.1 の並びのまま最初に当てると、当てる相手が 1 件もありません。** 排除する語は 1 件も働かず、規則辞書へクリシェの語を足しても効きません（issue #161）。**この PR で直しました。**

**正規化を、禁止入力の検出より先に置きます。** 検出は文章を舐めますので、長さの上限を通していない文字列を渡すと、際限なく時間がかかります。**形の誤りは、項目名を添えて先に返します。**
