**記録を実態に合わせて直してください。** 併せて、組み立ての段で長さの上限を設けることを

- 基準：OWASP10 A03 / A04、CC

## 3. 残っている提案（この PR で扱わなくて構いません）

### 3-1 文と文の区切りが半角空白です

`ja.yml` の `labels.sentence_separator: " "` により、弱めた色とそのままの色が
両方ある場合に次のようになります。

```
…画面全体を塗る色になっていませんか。 deep teal は、AI っぽさを避ける規則に…
```

**日本語の文の間に半角空白を置きます。** 画面（issue #73）では 1 文ずつ配列で
返して段落を分けるほうが、CRAP の近接・整列に沿います。表示を決める PR で
ご検討ください。

### 3-2 3 案目で、確かめることと調整したことがほぼ同じ文になります

```
[確かめること] この案は具体物を置かないため、人物の指示を外しています。…
[調整したこと] この案は具体物を置かないため、人物の写り方の指示を外しました。
```

伝わる内容は正しいのですが、同じ理由を 2 度読ませます。DP の DRY と
CRAP の反復の観点から、画面側でまとめる余地があります。

### 3-3 役割の呼び名の網羅を、テストで固定していません

1-3 のとおり、呼び名が無い役割はその場で失敗します。**方針は正しいです。**
ただし `variation_rules.yml` の `drops` へ 1 語足すだけで本番が落ちます。
`drops` に並ぶ役割がすべて `labels.roles` を持つことを確かめる例を足すと、
規則を編集した時点で気づけます。

### 3-4 `StylePalette::NOTE_KIND` の分岐だけテストがありません

実測では正しく出ます（`illustration` ・ `brand_colors: ['#0E7C7B']` で
「絵のスタイルが持つ配色の指定は、ブランドカラーを優先するため弱めました。」を確認）。
テストが無い 1 分岐として記録に残します。
