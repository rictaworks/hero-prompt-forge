## 見つかった要対応（2 件）

### 1. ブラウザで開くと、管理画面のすべての画面が 500 になります

```

```

API モード（`config.api_only = true`）では `ActionDispatch::Flash` が組み込まれていません。**この PR で共通の枠へ `flash` の 2 行が入ったため、どの画面もこの行で落ちます。**

**リクエストテストでは表に出ません。** テスト側が `flash` を参照して読み込むため、テストの中でだけ動きます。
