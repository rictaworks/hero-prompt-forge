## requirements.md との差

**仕様の正は [requirements.md](../requirements.md) です。** この下の文書は、**いま動いているもの**を写したものです。

**いまの実装が仕様に届いていない点**は、次のとおりです。

| 仕様 | いまの実装 | 追っている場所 |
|---|---|---|
| プロンプト精緻化に LangSmith ・ LangGraph を含みます（3） | **LangChain 経由の呼び出しまでです。** 追跡（LangSmith）を有効にしていません | 送る内容と保管期間を決めるまで使いません |
| 測定軸（7.1） | 8 つの軸のうち **6 つを出しています。** 上限到達と返還は日ごとの件数として記録し（`metric_events`）、生成リクエスト数・評価メモの記録率・再生成率・縮退比率は、既存の表から集計します | **コピーされた案の分布と稼働率を記録していません。** 管理画面にその旨を断り書きとして出しています |

**上の 2 点以外に、仕様と食い違う実装はありません。**
