WHAT WE DO

Three Guards

出力されるすべての案が、この3つの規則を通過します。通過しない案は出力されません。

Anti-Cliché Rules

紫〜ティールのグラデーション、浮遊する3Dオブジェクト、過剰な彩度を辞書で常時排除し、対応するネガティブプロンプトを自動で注入します。

Photographic Spec

実写系はレンズ焦点距離・キーライト／フィルライト／リムライト・被写界深度を必ず明示します。撮影指示を欠く案は出力しません。

Copy Space Guard

見出しとCTAを載せる余白を三分割構図で確保し、被写体と視線誘導が余白側と競合しない配置を指示します。

OUR PROCESS

From Input to Package

入力から3案の受け取りまで、4段階で処理されます。

Step 01

Input

業種・スタイル系統・生成モデルの3項目を選び、必要に応じてサービス概要とブランド条件を加えます。

Step 02

Rules

アンチAIルック規則とスタイル仕様化規則を適用し、入力の矛盾を優先順位に従って統合します。

Step 03

Refine

モデル別の記法へ整形し、非同期ジョブでLLMが表現を磨き込みます。障害時は辞書のみの合成へ縮退します。

Step 04

Package

構図の異なる3案を、ネガティブプロンプト・推奨パラメータ・アートディレクションノート付きで受け取ります。

FAQ

Before You Start

画像生成は行いません。出力はプロンプトパッケージのみで、生成はお使いの画像生成サービス側で実行してください。

実在人物名・企業ロゴ・第三者著作物への言及を検出した場合は生成を行わず、理由を添えてエラーを返します。

サービス概要は日本語で入力できます。日本語固有名詞は翻訳せずローマ字表記で保持し、意味説明を併記します。
